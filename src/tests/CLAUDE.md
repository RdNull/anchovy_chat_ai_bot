# Testing notes detail

Loaded automatically when Claude reads a file under `src/tests/`. The root `CLAUDE.md` keeps the destructive-action guard around `test_data` (it must stay resident — its trigger is writing a scratch script, not editing a test) and the pointer to the `write-tests` skill; this file has everything else.

`pytest.toml` sets `pythonpath = ["src"]` and `asyncio_mode = "auto"`. Test env vars (incl. `DATABASE_NAME=test_data`) are set in `[pytest_env]` — no `.env` file needed for tests.

Run tests inside Docker: `docker compose exec bot pytest`

All tests live in `src/tests/`. Shared fixtures are in `src/tests/conftest.py`. `src/tests/test_tools.py` covers the tools, including `search_web`'s parsing, failure and rate-limit paths — its autouse fixture clears the module-level limiter, whose window otherwise leaks between tests — and `find_stickers`'s query clamp, bare-string tolerance, rank fusion, hydrate-once accounting and log line, plus `send_sticker`'s eviction and failure paths;  `src/tests/test_model_manager.py` asserts the OpenRouter `plugins` key survives both config load and model construction, since `requirements.txt` pins no `langchain-openrouter` version and a dropped key answers from training data instead of erroring. Memory tests are split by module under `src/tests/memory/` (`test_memory.py`, `test_dedup.py`, `test_decay.py`); the cleanup task is covered by `src/tests/test_tasks_memory.py`, and the trigger/fetch-cap settings and their validator by `src/tests/test_settings.py`. Window-intake behaviour — oldest-first fetch, the watermark stamp, and the backlog/boundary deferral for both the memory and embedding passes — lives in `src/tests/test_context.py`. Sticker coverage is split by layer: intake flags in `test_handlers.py` (including the load-bearing assertion that a **photo** is not a sticker) and `media/test_messages_media.py`, the index in `test_embeddings.py`, the tools in `test_tools.py`, tool binding in `test_character.py`, and the boot log in `test_bot_init.py`. `src/tests/test_logs.py` covers the bot-token redaction — that it survives the second format pass the filter's own rewrite forces, that unrelated records keep their lazy arguments, and that the filter is actually wired into the root handlers. Initiative coverage is split by module under `src/tests/initiative/` (`test_handlers.py`, `test_policies.py`, `test_processors.py`, `test_repository.py`): the claim lock is asserted by running two `run_initiative_checks` concurrently under `asyncio.gather` and demanding exactly one evaluation, and `pre_check`'s newest-message guard is asserted in both directions (a bot message newest but not at the window tail must block; a bot message at the tail but not newest must not), and `_get_messages` is asserted against a real backlog to take the newest messages past the watermark. The `run_context_checks` stage guard lives in `test_context.py`, and `[TARGET]` marking in `test_character.py`. Deploy-config invariants — every manifest placeholder exported by the workflow, with the shell guard bounded by that set in both directions — live in `src/tests/test_deploy_config.py`; it reads `.github/workflows/deploy.yml`, every YAML under `manifests/` and `deploy-k8s.sh` off disk, so it needs no cluster. The blackbox tools are covered in `src/tests/blackbox/test_queries.py` against `queries.py` alone; Qdrant is patched there, and the tests assert neither `_check_collection` nor `create_collection` runs. The HTTP surface is `src/tests/blackbox/test_app.py`, through `starlette.testclient.TestClient` used as a context manager so the lifespan runs. It covers:
- the auth outcomes: missing, wrong and `Basic` tokens, case-insensitive `Bearer`, and `initialize` + `tools/list` returning all seven tools with the right token
- both probes, including a hung store under a shrunk `_READY_TIMEOUT`
- the blank-token refusal
- `BearerAuth` around a stub app, asserting a rejected request never calls it and never awaits `receive`
- `caplog`, asserting neither the token nor a body marker reaches any record

`src/tests/test_dns_sync.py` loads `scripts/dns_sync.py` by file path — `pythonpath = ["src"]` makes `import scripts` resolve to `src/scripts` — and drives `sync` through one `httpx.MockTransport` that records every request, so "no write" is asserted as the absence of a PUT. It covers ExternalIP-over-InternalIP, IPv6 skipped, the private ranges (and that 172.104.x is not one), and the refusal log line.

Production modules must not carry test-only helpers — reset hooks, clear functions, injection seams. A test that needs past a module's public surface reaches for the private itself, from the test layer: `src/tests/test_tools.py` clears `_web_search_limiter._call_times` in an autouse fixture rather than the module exposing a reset. Module-level state that leaks between tests is the usual reason this comes up, and it is often a sign the global should not exist.

Use `[write-tests](.claude/skills/write-tests)` skill for tests manipulation.
